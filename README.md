# LangChain Hello World 🚀

A Python-based AI application built with **LangChain and OpenAI** that processes large amounts of text and transforms them into short, meaningful summaries, key insights, and interesting fun facts.

## ✨ Features

- **AI Summarization:** Condenses lengthy text into a few easy-to-read lines.
- **Key Insights:** Extracts important information and main takeaways.
- **Fun Facts:** Discovers interesting facts hidden within the content.
- **LangChain Integration:** Uses prompt templates and LCEL chains for AI processing.

## 🛠️ Tech Stack

- Python
- LangChain
- OpenAI API
- uv (Package Manager)

## 🚀 Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/malikqaiser91/LangChain-Hello-World.git
cd LangChain-Hello-World
```

**2. Install dependencies**

```bash
uv sync
```

**3. Configure your API key**

Create a `.env` file:

```env
OPENAI_API_KEY=your_api_key_here
```

**4. Run the application**

Run your project's Python entry-point script using `uv run`.
